# การ์ดเชิญงานแต่ง · วรัชยา & ณัชชนก

ลิงก์การ์ด: **https://vanshrrg.github.io/natchanok-waratchaya/**

## แก้ไขข้อมูล
แก้ทุกอย่างที่ไฟล์ **`config.js`** (ชื่อ วันที่ เวลา สถานที่ ลิงก์แผนที่ วันปิดรับ RSVP ลิงก์ระบบตอบรับ)

## ใส่รูป / โลโก้ / เพลง
วางไฟล์ในโฟลเดอร์ `assets/` ด้วยชื่อนี้ — การ์ดจะแสดงเองอัตโนมัติ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `assets/logo.png` | โลโก้บนหน้าปก (แทนตัวอักษร G E) — แนะนำ PNG พื้นใส |
| `assets/hero.jpg` | รูปในกรอบโค้ง (แนวตั้ง ~ 3:4) |
| `assets/music.mp3` | เพลงพื้นหลัง — ปุ่ม ♪ จะโผล่เองเมื่อมีไฟล์ |
| `assets/og.jpg` | รูปพรีวิวเวลาแชร์ใน LINE/Facebook (1200×630) |

## ตั้งค่า RSVP ให้ลงชีต "ตอบรับแขก"
คำตอบจากการ์ดจะถูกเพิ่มเป็นแถวใหม่ในแท็บ **ตอบรับแขก** ของไฟล์ *WEDDING ค่าใช้จ่ายงานแต่ง* (ทำครั้งเดียว)
1. เปิดไฟล์ Google Sheets นั้น → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในหน้า `Code.gs` ทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ **`tools/rsvp-apps-script.gs`** → กด 💾 บันทึก
3. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: ⚙️ → **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
   - กด Deploy → อนุญาตสิทธิ์ (Authorize access) ด้วยบัญชี Google ของคุณ
4. คัดลอก **URL ของเว็บแอป** (ขึ้นต้นด้วย `https://script.google.com/macros/s/` ลงท้าย `/exec`)
5. วาง URL ใน `config.js` ที่ `rsvpEndpoint: "..."` แล้วอัปเดตการ์ดออนไลน์

ถ้าแก้โค้ด Apps Script ภายหลัง ให้ Deploy → **จัดการการทำให้ใช้งานได้ (Manage deployments)** → ✏️ → เวอร์ชันใหม่ เพื่อให้ URL เดิมใช้โค้ดใหม่
แถวแรกของแท็บจะเป็นหัวตาราง: เวลา · ชื่อ - นามสกุล · มาร่วมงาน · จำนวนผู้ร่วมงาน · คำอวยพร

## อัปเดตการ์ดออนไลน์

```bash
git add -A

git push
```
GitHub Pages จะอัปเดตภายใน ~1 นาที

## ดูตัวอย่างในเครื่อง
```bash
node tools/serve.js
```
แล้วเปิด http://localhost:5500 — ถ้าเปลี่ยนชื่อ/วันที่ ให้สร้างรูปแชร์ใหม่ที่ http://localhost:5500/tools/og.html → กด Save
